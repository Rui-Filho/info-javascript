# 📚 JavaScript.info — Estudos de JavaScript

Repositório criado para registrar minha trajetória de estudos de **JavaScript** utilizando como principal referência o [JavaScript.info](https://javascript.info/).

O conteúdo reúne exemplos, anotações e exercícios desenvolvidos durante o estudo dos fundamentos da linguagem, acompanhando minha evolução de forma organizada e progressiva.

---

## 🎯 Sobre o estudo

O **JavaScript.info** é uma das principais referências utilizadas durante meus estudos de JavaScript.

Este repositório tem como objetivo registrar, na prática, os conceitos estudados, permitindo revisar o conteúdo, acompanhar minha evolução e manter um histórico do processo de aprendizagem.

Os exemplos são desenvolvidos e testados durante os estudos, buscando não apenas reproduzir o conteúdo da documentação, mas compreender como e por que cada recurso da linguagem funciona.

---
